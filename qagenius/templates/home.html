How the key works

QA-Genius has no accounts and no database. You paste an API key from Google Gemini, OpenAI or another provider; it is saved in this browser's storage and sent with each request you make. The server uses it for that one call and never stores or logs it. Add more than one and a busy or rejected key falls through to the next.

Quality insights reads reports with plain code — that desk needs no key at all.
