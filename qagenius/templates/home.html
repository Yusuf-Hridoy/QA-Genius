How the key works

QA-Genius has no accounts and no database. You paste an API key from Google Gemini, OpenAI or another provider. It is saved in this browser and sent with each request you make. The server uses it for that one call and never saves or logs it. Add more than one key and QA-Genius tries the next one when a key is busy or refused.
